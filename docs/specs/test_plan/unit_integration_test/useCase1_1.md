使用案例1.1 動物列表瀏覽
■ 填表人：系統分析師
■ 商業流程編號：BP-ANIMAL-002
■ 行為者：所有使用者
■ 內容概述：本案例描述使用者如何檢視動物清單與瀏覽狀態。
■ 先決條件：使用者已訪問平台首頁或動物瀏覽頁面。
■ 後置條件：無。
■ 主要流程：
使用者進入「尋找動物」頁面。
系統顯示動物清單，包含動物圖片、名稱、物種、年齡、性別等基本資訊。
系統依「最新上架」順序排序動物資料。
使用者可以點選動物卡片進入詳情頁面。
■ 輔助說明：
若登入角色為訪客，僅能瀏覽公開動物資料。
若登入角色為會員，可看到更多動物詳細資訊與操作選項。
動物狀態為「已領養」或「下架」時，不會顯示在清單中。
